# GroceryShop
Web Application for Grocery Store
The Grocery Store Web Application is a full-stack web platform developed using Vue.js for the frontend and Flask for the backend. The application allows users to browse products by category, search for products, view product details, and add items to a shopping cart. Users can place orders, view their order history, and experience a simulated payment process. The system also supports user authentication and role-based access using Flask-Security, allowing secure login and registration for customers and administrators. The admin panel enables administrators to manage products, categories, stock, and apply promotional offers to individual products or entire categories. Additional features include cart management, offer calculation with discounted pricing, background email notifications using Celery, and a responsive interface designed with Bootstrap. This project demonstrates full-stack development, REST API integration, authentication, and database management.
